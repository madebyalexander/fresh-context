# Changelog

## 0.1.0

First release.

- `working-lean` skill: rules for small tool output, ranged reads, batched calls, subagent budgets and handoffs; references for settings, handoffs and measuring.
- `/handoff` and `/tokens`.
- Hooks: handoff list at session start, compaction summary saved, cold-resume warning, big-session nudge, snapshot before compaction and at session end.
- Scripts: `quiet`, `outline`, `jpick`, `tokens`, `statusline.py`.
- `npx fresh-context` installer: copies the plugin to a per-user folder, adds it as a marketplace and installs it; `uninstall` and `--dry-run`. No dependencies, Node 18+.
